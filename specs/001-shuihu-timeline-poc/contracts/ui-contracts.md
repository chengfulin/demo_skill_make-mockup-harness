# UI Contracts: 水滸傳角色事件時間軸（一頁式前端 POC）

**Feature**: `001-shuihu-timeline-poc` | **Date**: 2026-10-29 | **Plan**: [../plan.md](../plan.md)

本檔是實作與 E2E 的畫面契約。依 spec「權威劃分」：區塊順序、互動流程、UI 文案以 Prototype v2 為準；領域術語與業務規則以 StoryBoard／spec 為準。
**逐字文案取自 Prototype DOM**（Playwright `innerText`、`placeholder`、`aria-label`，1440×900，淺色）。`<…>` 為資料帶入的值；「共 54 個事件」等數字與中文間的空白為視覺間距，DOM 斷言前會正規化（見 plan「Prototype 並列比對 E2E」）。
token 見 [research.md「設計 token」](../research.md#設計-token)，資料欄位見 [data-model.md](../data-model.md)。

## 通用規則

- 每個畫面根元素保留 Prototype 的 `data-page` 值：`S1 角色篩選列`、`S2 時間軸`、`S3 事件明細面板`、`S4 角色資料面板`、`S5 地圖`、`S6 關係圖`。
- `data-testid` 只加在下表列出的元素；其餘以 role／label／文字定位。
- 文案中的數字（人物數、事件數）一律由資料計算，不寫死。
- 鍵盤：可點元素皆為 `<button>` 或帶 `role="button"`＋`tabindex="0"` 的 SVG 群組，Enter／Space 觸發；Escape 或點遮罩關閉面板（G-10、AC-S24）。

## S1 角色篩選列（US2、US3、US5 入口；三視圖常駐＝三個視圖都渲染於頁面上方、不 sticky，FR-005、AC-S13）

### 區塊順序

`section.filter[data-page="S1 角色篩選列"]` 內依序：
1. 工具列 `row`：搜尋框 → 「天罡」→「地煞」→ 大節選單
2. 角色清單 `chars`（`data-testid="char-list"`）
3. 已選列 `sel`（`data-testid="selected-bar"`）
4. 結果列 `bar`：結果數（`data-testid="result-count"`）→ 視圖分頁（`role="tablist"`）

### 元件對照

| 區塊 | 元件（`components/FilterBar/`） | 容器／狀態 |
| :---- | :---- | :---- |
| 搜尋 | `SearchBox`（`<input type="search">`，左側放大鏡 SVG） | `setQuery`、`submitSearch`（Enter） |
| 快選 | `GroupToggle` ×2（`aria-pressed`＝群組已全選） | `toggleGroup` |
| 大節 | `ArcSelect`（`<select aria-label="大節">`） | `selectArc` |
| 角色清單 | `CharacterChip`（`pick` 鈕＋`info` 鈕）＋`Avatar` | `toggleCharacter`、`openCharacter` |
| 已選列 | `SelectedTags` | `removeCharacter`、`clearCharacters` |
| 結果數 | `ResultCount`（`aria-live="polite"`） | selector |
| 視圖分頁 | `ViewTabs`（`role="tab"`、`aria-selected`） | `setView` |

### 逐字文案與狀態

| 元素 | 文案 | 狀態／條件 |
| :---- | :---- | :---- |
| 搜尋框 placeholder | 搜尋姓名或綽號，例如：黑旋風 | `aria-label`「搜尋角色」 |
| 快選鈕 | 天罡、地煞（前置群組色圓點） | 群組全選時 `aria-pressed="true"`，底色反白 |
| 大節選單第一項 | 全部大節（第 1–120 回） | 值為空 |
| 大節選單其他項 | <大節名>（第 <a>–<b> 回） | 例「魂聚蓼兒洼（第 120–120 回）」 |
| chip | <頭像字> <姓名> <主綽號> ＋ i | 已選：`aria-pressed="true"`、外框與底色換 accent；高俅無綽號只顯示姓名 |
| chip 資料鈕 | i | `aria-label`「<姓名> 角色資料」、`title`「角色資料」；不改變選取（AC-S12） |
| 搜尋無結果 | 找不到符合的角色 | 取代整個 chip 清單 |
| 已選列（未選） | 未選角色，顯示全部角色的事件 | — |
| 已選列（有選） | 已選 ＋ 每位「<姓名> ×」＋ 清除全部 | 標籤依加入順序；× 的 `aria-label`「移除 <姓名>」 |
| 結果數 | 共 <N> 個事件 | N 為目前篩選結果數（含大節） |
| 視圖分頁 | 時間軸、地圖、關係圖 | 目前視圖 `aria-selected="true"`、實心底 |

### 行為

- 即打即篩：比對姓名與綽號清單（D-5）；Enter 選取清單第一個且未被選取者以外不動作（D-3）。
- 快選：G-7（未全選→加入全部並保留其他；已全選→只移除該群組）。
- ≤720px：chip 列改單列橫向捲動。

### 偏離

- D-3（Enter 只選取不取消）、D-5（搜尋只比對姓名與綽號，不比對綽號字串中的說明字）。
