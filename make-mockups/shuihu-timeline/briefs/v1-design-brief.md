# 水滸傳角色事件時間軸 Design Brief v1

> mockup 的製作指示。來源：`storyboard.md` v1。步驟 3 依本檔撰寫 `mockup-src/index.html`。
> 正文只放畫面與規則；假資料見文末附表。

## 目標與情境
粉絲向單頁網站，把《水滸傳》百二十回本的主要角色與事件對照章回排成時間軸。讀過的書迷回顧角色經歷，正在讀的讀者邊讀邊查；訪客挑選認識的角色篩出相關事件，並以地圖、關係圖補充理解。

## 設計系統
- 不套設計系統，依 artifact-design 規範自訂視覺。
- 方向建議：宋版書／水墨的古典氣質，但介面保持現代易讀；正文用襯線中文字（如 Noto Serif TC），介面元件用無襯線（Noto Sans TC），皆需系統字型 fallback；支援淺色與深色主題。

## 使用者角色與展示列
單一角色（訪客，唯讀、免登入），不放展示列。

| 角色 | 預設 | 畫面差異 |
|---|---|---|
| 訪客 | 是 | 全部內容皆可見，不做防劇透 |

## 畫面清單
> 單頁網站：頁首固定「角色篩選列」，下方以分頁切換三個視圖（時間軸／地圖／關係圖），事件明細與角色資料以右側面板疊在視圖上。

### S1 角色篩選列
- **對應 User Story**：US-02、US-03
- **目的**：挑選角色與大節，三個視圖共用。
- **主要元素**：
  - 搜尋框（placeholder「搜尋姓名或綽號，例如：黑旋風」）
  - 快選鈕「天罡」「地煞」（toggle 樣式）
  - 角色清單：頭像（以姓氏單字的圓形徽章代替圖片，依星號群組配色）＋姓名＋綽號，可橫向捲動或展開成格狀
  - 已選標籤區：每個標籤有「×」，另有「清除全部」
  - 大節下拉選單：「全部大節」＋各大節（名稱＋第 a–b 回）
  - 視圖分頁：時間軸／地圖／關係圖
  - 結果數：「共 N 個事件」
- **狀態**：未選角色（顯示「全部角色」）、已選 1 位、已選多位；搜尋無結果時清單顯示「找不到符合的角色」。
- **行為規則**：
  - 多選角色取聯集；角色與大節並用取交集
  - 搜尋即打即篩，比對姓名與綽號
  - 天罡／地煞快選把收錄名單中該群組角色全選，再按一次取消；非一百單八將不受影響
  - 角色頭像旁有小「i」圖示，點擊開啟 S4 角色資料
  - 切換視圖時篩選條件保留
- **跳轉**：點「i」→ S4；切換分頁 → S2／S5／S6。
- **假資料**：附表 B 全部角色、附表 A 全部大節。

### S2 時間軸
- **對應 User Story**：US-01、US-03
- **目的**：依章回呈現事件，預設視圖。
- **主要元素**：
  - 章回刻度（1–120，每 10 回一個主刻度），依大節分段並以色帶與標題標示
  - 事件卡：事件名、「第 a–b 回」、最多 3 個角色頭像＋「+N」；跨多回以長條、單回以點
  - 重疊事件上下錯開成多軌
  - 已選角色的頭像在事件卡上加框強調
- **狀態**：
  - 全部事件（預設）
  - 篩選後
  - 空狀態：「沒有符合條件的事件」＋「清除篩選」
- **行為規則**：
  - 選定大節時，時間軸只顯示該大節章回範圍並放大
  - 點大節標題等同選取該大節
  - 點事件卡開啟 S3
  - 時間軸可水平捲動；窄螢幕改為直向時間軸（章回由上到下）
- **跳轉**：事件卡 → S3；大節標題 → 套用大節篩選。
- **假資料**：附表 C 全部事件。

### S3 事件明細面板
- **對應 User Story**：US-04
- **目的**：顯示事件完整資訊，並延伸到角色、地點。
- **主要元素**：事件名、所屬大節、章回區間與各回回目（附表 D）、地點（可點）、參與角色（頭像＋名字）、摘要、「上一個／下一個事件」、關閉鈕。
- **狀態**：開啟／關閉；第一個或最後一個事件時對應的切換鈕停用。
- **行為規則**：
  - 右側滑出面板，不離開目前視圖；窄螢幕改為底部抽屜
  - 點角色頭像把角色加入篩選；點名字開啟 S4
  - 點地點切到 S5 並聚焦該地點
  - 上一個／下一個依目前篩選結果順序
- **跳轉**：→ S4、→ S5。
- **假資料**：以「大鬧野豬林」「智取生辰綱」為展示主例。

### S4 角色資料面板
- **對應 User Story**：US-05
- **目的**：角色一生的資料與狀態。
- **主要元素**：
  - 姓名、綽號、星號與座次（非一百單八將標「非一百單八將」）、結局簡述
  - 狀態條：1–120 回，四色區段（未登場／在野／已上梁山／已死亡或離散），標出登場回、上梁山回、結局回三個節點，附圖例
  - 參與事件清單（章回排序，可點）
  - 關係清單（對象＋關係類型，可點）
  - 「只看此角色」按鈕
- **狀態**：依角色資料推算的四種狀態；未曾上梁山者（高俅）沒有「已上梁山」段；全書終了仍在世者最後一段為「已上梁山」。
- **行為規則**：
  - 狀態優先序：已死亡或離散 > 已上梁山 > 在野 > 未登場
  - 「離開但未死」（公孫勝歸山、燕青隱去、武松出家等）歸「已死亡或離散」
  - 點事件 → S3；點關係對象 → 切換為對方的 S4
  - 「只看此角色」將篩選設為僅此一人
- **跳轉**：→ S3、→ S4（他人）。
- **假資料**：附表 B；展示主例林沖、晁蓋、高俅。

### S5 地圖
- **對應 User Story**：US-06
- **目的**：篩選後事件的地點分布與單一角色行跡。
- **主要元素**：
  - 北宋疆域示意地圖（inline SVG：概略海岸線、黃河、長江、梁山泊水域；不用外部底圖），角落註明「示意，非精確測繪」
  - 地點標記＋事件數徽章
  - 只選一位角色時，依事件章回順序的虛線行跡，線上標順序號
  - 地圖下方精簡章回刻度，標示目前篩選範圍
  - 角落提示「N 個事件無法標示地點」（N>0 時才顯示）
- **狀態**：無篩選（全部地點）、單一角色（顯示行跡）、多角色（只有標記）、空狀態。
- **行為規則**：
  - 點標記彈出該地事件清單，點事件開啟 S3
  - 從 S3 點地點進入時，該標記高亮並彈出清單
- **跳轉**：→ S3。
- **假資料**：附表 E 地點與座標；至少 1 個事件地點設為無法定位，用來展示提示。

### S6 關係圖
- **對應 User Story**：US-07
- **目的**：角色之間的關係網絡。
- **主要元素**：
  - 節點（依天罡／地煞／其他配色）、連線（依關係類型區分線型或顏色）、圖例
  - 節點上的「＋」加入篩選
- **狀態**：未選角色（全體）；已選角色（已選者居中，直接相連者清楚顯示，其他淡出）。
- **行為規則**：
  - 只展開一層關係
  - 點節點開啟 S4
  - 版面可用預先算好的固定座標（約 20 個節點），不需力導向動畫
- **跳轉**：→ S4。
- **假資料**：附表 F 關係。

## 全域規則
- 角色篩選、大節篩選在三個視圖共用並保留。
- 未選角色＝全部角色。多選角色取聯集；角色與大節取交集。
- 角色狀態依登場回、上梁山回、結局回推算，優先序：已死亡或離散 > 已上梁山 > 在野 > 未登場。
- 不做防劇透。
- 章回編號一律以百二十回本為準。

## 展示腳本
1. 進站看到全書時間軸以大節分段，結果數「共 N 個事件」（S2）
2. 搜尋「豹子頭」選取林沖，時間軸只剩林沖的事件（S1、S2）
3. 點「大鬧野豬林」看事件明細，點魯智深頭像加入篩選，時間軸變為兩人事件聯集（S3、S2）
4. 點林沖名字開啟角色資料，看狀態條從在野、上梁山到結局（S4）
5. 按「只看此角色」，切換到地圖看林沖的行跡線（S4、S5）
6. 切換到關係圖，看林沖與魯智深、高俅等人的關係，點節點開啟對方資料（S6、S4）

## 本階段不涵蓋
- 章回原文閱讀、分享連結、匯出圖片
- 「共同出場」（交集）角色篩選、儲存篩選條件
- 自訂起訖回的章回範圍篩選、多選大節
- 事件評論或筆記
- 角色兵器、武藝等延伸百科資料
- 真實地理底圖、城市街道層級縮放、多角色行跡同時比對
- 關係隨章回演變、兩層以上關係展開

## 製作要求
- 所有畫面放在同一個 HTML 檔（`mockup-src/index.html`），每個畫面的根元素加 `data-page="S{n} {畫面名稱}"`。
- 狀態要能實際操作，以本檔假資料驅動；單一角色，不放展示列。
- 不載入外部圖片；圖示、地圖用 inline SVG；字型可用 Google Fonts，需有系統字型 fallback。
- 不要自行新增 brief 未提及的功能；想到的建議列成「待確認」，不要直接做進畫面。

### 查證備註

- 全部章回號以維基文庫「水滸傳 (120回本)」（明末袁無涯刊《忠義水滸全傳》）為準；第1–90回與百回本相同，第91–110回為插入的征田虎（91–100）、征王慶（101–110），征方臘為第111–119回（百回本為91–99回）。
- 維基百科〈一百單八將〉表格之初登場／入山回數部分以百回本為底（如其註明征方臘為『第110回~第119回』，與實際 111–119 不合），本資料已逐一以維基文庫 120 回本原文關鍵字檢索覆核。
- joinChapter 定義為「正式坐交椅入夥」之回：林沖於第11回即坐第四位交椅（維基百科表列第12回）；晁蓋一夥第19回奪泊、第20回排位，取20。
- 燕青 joinChapter：維基百科表列第62回，但第62回燕青僅欲上梁山求救、途中遇楊雄石秀；本資料取盧俊義正式上山之第67回（原文『就叫燕青一處安歇』），屬詮釋差異。
- 武松 firstChapter=22：第22回末以『那漢』登場（未道姓名），姓名於第23回揭曉。
- 戴宗第36回回目已被提及（吳用舉戴宗），本人登場為第38回；盧俊義第60回已被提及，登場為第61回；花榮第22回已被提及，登場為第33回；扈三娘第47回已被提及，登場為第48回。firstChapter 一律取本人登場回。
- 宋江 nickname：一般以『及時雨』稱之，座次石碣所題綽號為『呼保義』（維基百科表），兩者並列。
- 晁蓋 star／rank 為 null：晁蓋不在一百單八將之列，無星宿與座次。
- 高俅 nickname／star／rank／joinChapter 為 null：反派，非梁山人物；書中僅有排行名『高二』、諢名『高毬』（第2回），不屬綽號，故不填。
- 高俅 fateChapter=120 意指其最後出場（被徽宗責罵），百二十回本中並無其死亡情節；史實及《水滸後傳》等續書另有說法，不採。
- 維基文庫目錄第38回作「黑旋風展浪裡白條」，但同站第38回正文標題作「黑旋風鬥浪裏白條」，5000yan 亦作「鬥」；chapters 依要求照錄目錄頁文字，疑目錄頁為錯字。
- 第97、100回目錄作「陳觀」，5000yan 作「陳瓘」，正文中亦出現「陳瓘」；照錄維基文庫目錄。
- 第13回維基文庫目錄作「青面獸北京鬥武 急先鋒東郭爭功」，5000yan 上下聯順序相反；照錄維基文庫。
- 公孫勝結局：百回本為征遼後離隊；百二十回本為征王慶後第110回拜別，本資料取後者（維基百科亦記『征王慶後退隱』）。
- chapters 回目的中文數字寫法依維基文庫目錄（如『第一百一回』『第一百十回』）。
