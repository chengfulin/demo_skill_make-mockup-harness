# 水滸傳角色事件時間軸 Story Board

## Introduction
一個粉絲向單頁網站，把《水滸傳》（百二十回本）的主要角色與事件對照章回排成時間軸。讀過的書迷用它回顧某位好漢的經歷，正在讀的讀者用它邊讀邊查人物前後脈絡。訪客挑選自己認識的角色，即可篩出相關事件，並從地圖與關係圖兩個角度補充理解。

## 使用者角色

| 角色 | 入口 | 關注點 |
| :---- | :---- | :---- |
| 訪客 | 直接開啟網站首頁（單頁、免登入、唯讀） | 找出自己認識的角色經歷了哪些事、在第幾回 |

## 資料關聯性
* 章回共 120 回，以百二十回本回目編號，為全站唯一的時間刻度
* 大節（故事階段）涵蓋一段連續章回，大節之間不重疊且依序涵蓋 1–120 回
* 每個事件對應一段連續章回區間（起回–迄回），並歸屬一個大節
* 事件與角色為多對多：一個事件有一至多位角色，一位角色參與多個事件
* 每個事件有一個地點；地點有示意地圖上的座標，同一地點可有多個事件
* 角色有姓名、綽號；梁山一百單八將另有星號（天罡／地煞）與座次
* 角色關係為兩位角色間的一條連線，帶關係類型（結義、師徒、主僕、仇敵、夫妻、兄弟）
* 收錄範圍 22 位角色、54 個事件，含非一百單八將的重要人物（如晁蓋、高俅）

## 全域規則
* 角色篩選、大節篩選在時間軸、地圖、關係圖三個視圖間共用，切換視圖時保留
* 未選任何角色時視為「全部角色」，不是「沒有結果」
* 多選角色時取聯集：事件只要含任一已選角色就顯示
* 角色篩選與大節篩選同時存在時取交集
* 角色在某一回的狀態依該角色的登場回、上梁山回、結局回推算（見 US-05）
* 不做防劇透：所有事件、結局、星號一律直接顯示

## User Story

### US-01 瀏覽全書時間軸

| As a ... | I want to... | so that... |
| :---- | :---- | :---- |
| 訪客 | 進站就看到依章回排列的全書事件 | 掌握整部小說的故事脈絡 |

- **需求來源**：2026-10-20 需求討論（進站畫面：全書時間軸＋角色選擇列）
- **定位**：網站的主畫面與預設視圖，所有篩選結果都回到這條時間軸呈現。
- **角色與入口**：訪客；開啟網站即進入，或從視圖切換點「時間軸」。
- **規則**：
  - 橫軸刻度為第 1–120 回，事件依起始回由早到晚排列
  - 時間軸以大節分段，每段顯示大節名稱與章回區間
  - 跨多回的事件以區間長條呈現，單回事件以點呈現
  - 事件卡顯示事件名、章回區間、主要角色頭像（最多 3 位，其餘以「+N」）
  - 點事件卡開啟事件明細（US-04）
  - 頂部顯示目前結果數，例如「共 54 個事件」
- **狀態**：無
- **範圍**：
  - 涵蓋：全書時間軸、大節分段、事件卡、結果數
  - 不涵蓋：章回原文閱讀、分享連結、匯出圖片
- **邊界情況**：
  - 多個事件章回區間重疊時，上下錯開排列，不互相遮蓋
- **驗收條件**：
  - Given 訪客首次進站且未選角色 / When 頁面載入 / Then 看到全部 54 個事件依章回排列，並以大節分段
  - Given 時間軸已顯示 / When 訪客點「智取生辰綱」事件卡 / Then 開啟該事件明細

### US-02 選擇角色篩選事件

| As a ... | I want to... | so that... |
| :---- | :---- | :---- |
| 訪客 | 挑出我認識的角色，只看他們的事件 | 快速追蹤特定人物的經歷 |

- **需求來源**：2026-10-20 需求討論（可選擇自己認識的角色篩選事件；多選取「任一」；需星號群組快選、關鍵字搜尋）
- **定位**：網站的核心互動，讓訪客從 120 回中只留下關心的角色相關事件。
- **角色與入口**：訪客；頁面上方的角色選擇列，三個視圖都看得到。
- **規則**：
  - 角色選擇列以頭像＋姓名列出所有收錄角色，可多選
  - 多選角色時，顯示含任一已選角色的事件
  - 已選角色以標籤列在選擇列上方，每個標籤可單獨移除，另有「清除全部」
  - 搜尋框依姓名或綽號比對，即打即篩角色清單（例如輸入「黑旋風」找到李逵）
  - 「天罡」「地煞」快選鈕把收錄名單中該群組的角色一次全選，再按一次取消
  - 篩選後，時間軸中已選角色的頭像加框強調
- **狀態**：無
- **範圍**：
  - 涵蓋：多選角色、搜尋角色、天罡／地煞快選、清除篩選
  - 不涵蓋：「共同出場」（交集）篩選、儲存篩選條件、分享篩選結果
- **邊界情況**：
  - 搜尋不到角色：角色清單顯示「找不到符合的角色」
  - 篩選結果為空（例如再疊加大節後無事件）：時間軸顯示空狀態與「清除篩選」
  - 非一百單八將的角色（如晁蓋、高俅）不屬於天罡或地煞，快選時不會被選入
- **驗收條件**：
  - Given 未選角色 / When 訪客選「武松」 / Then 時間軸只剩武松參與的事件，結果數同步更新
  - Given 已選武松 / When 再選「魯智深」 / Then 顯示含武松或魯智深的事件（聯集）
  - Given 搜尋框為空 / When 輸入「豹子頭」 / Then 角色清單只剩林沖
  - Given 未選角色 / When 按「天罡」 / Then 收錄名單中的天罡角色全部被選取，晁蓋不在其中

### US-03 依大節篩選

| As a ... | I want to... | so that... |
| :---- | :---- | :---- |
| 訪客 | 只看某個故事階段的事件 | 聚焦在我正在讀或想回顧的段落 |

- **需求來源**：2026-10-20 需求討論（篩選條件：大節）
- **定位**：讓訪客以故事階段縮小範圍，可與角色篩選併用。
- **角色與入口**：訪客；時間軸上方的大節選單，或點時間軸上的大節標題。
- **規則**：
  - 大節選單列出所有大節與章回區間，可單選，另有「全部大節」
  - 選定大節後，時間軸只顯示該大節的章回刻度與事件
  - 點時間軸上的大節標題等同從選單選取該大節
  - 與角色篩選併用時取交集
- **狀態**：無
- **範圍**：
  - 涵蓋：單選大節、回到全部大節
  - 不涵蓋：自訂起訖回的章回範圍篩選、多選大節
- **驗收條件**：
  - Given 未設任何篩選 / When 選「三打祝家莊」大節 / Then 時間軸只顯示該大節的章回與事件
  - Given 已選大節「征方臘」與角色「武松」 / When 檢視時間軸 / Then 只顯示征方臘期間有武松的事件

### US-04 檢視事件明細

| As a ... | I want to... | so that... |
| :---- | :---- | :---- |
| 訪客 | 打開事件看發生在哪、誰參與、在第幾回 | 回想或找到原書對應的段落 |

- **需求來源**：2026-10-20 需求討論（角色與相關事件對照章節）
- **定位**：事件的完整資訊面板，也是從事件延伸到其他角色的入口。
- **角色與入口**：訪客；點時間軸事件卡或地圖上的事件標記。
- **規則**：
  - 明細以側邊面板開啟，不離開目前視圖
  - 顯示事件名、章回區間及各回回目、所屬大節、地點、參與角色、一兩句摘要
  - 點參與角色的頭像，把該角色加入角色篩選
  - 點參與角色的名字，開啟該角色資料（US-05）
  - 點地點，切換到地圖視圖並定位到該地點
  - 面板提供「上一個／下一個事件」，依目前篩選結果的順序切換
- **狀態**：無
- **範圍**：
  - 涵蓋：事件資訊、從事件跳到角色或地點、前後事件切換
  - 不涵蓋：章回原文、事件評論或筆記
- **驗收條件**：
  - Given 時間軸已顯示 / When 點「醉打蔣門神・血濺鴛鴦樓」 / Then 面板顯示第 28–31 回及各回回目、地點孟州、參與角色武松
  - Given 已選林沖且「大鬧野豬林」面板開啟 / When 點參與角色「魯智深」的頭像 / Then 魯智深加入角色篩選，時間軸同步更新

### US-05 檢視角色資料與狀態

| As a ... | I want to... | so that... |
| :---- | :---- | :---- |
| 訪客 | 看某角色的綽號、星號與一生的狀態變化 | 一眼看懂這個人在書中的起落 |

- **需求來源**：2026-10-20 需求討論（資料物件：星號、角色關係；狀態：未登場／在野／已上梁山／已死亡或離散）
- **定位**：角色的個人頁面板，把角色在 120 回中的狀態與參與事件濃縮在一處。
- **角色與入口**：訪客；點事件明細中的角色名、角色選擇列頭像的「資料」圖示、關係圖節點。
- **規則**：
  - 顯示姓名、綽號、星號與座次（非一百單八將顯示「非一百單八將」）、結局簡述
  - 顯示一條 1–120 回的狀態條，以四種顏色區段標示該角色各回的狀態
  - 狀態條上標出登場回、上梁山回、結局回三個節點
  - 列出該角色參與的事件，依章回排序，點擊開啟事件明細
  - 列出該角色的關係（對象、關係類型），點對象開啟對方資料
  - 提供「只看此角色」按鈕，將角色篩選設為僅此一人
- **狀態**：角色在某一回的狀態：未登場（登場回之前）→ 在野（登場回起）→ 已上梁山（上梁山回起）→ 已死亡或離散（結局回起）。
  顯示優先序：已死亡或離散 > 已上梁山 > 在野 > 未登場。未曾上梁山的角色跳過「已上梁山」；書中未死也未離開的角色（如高俅）沒有結局回，全書維持「在野」。
- **範圍**：
  - 涵蓋：角色基本資料、狀態條、參與事件清單、關係清單
  - 不涵蓋：角色兵器、武藝等延伸百科資料
- **邊界情況**：
  - 結局在全書終了時仍在世的角色：狀態條最後一段為「已上梁山」，結局欄寫明（如受封、隱去）
  - 離開梁山但未死（如公孫勝歸山、燕青隱去）：歸類為「已死亡或離散」
- **驗收條件**：
  - Given 訪客開啟晁蓋資料 / When 檢視狀態條 / Then 曾頭市中箭身亡那一回起顯示為「已死亡或離散」，標示「非一百單八將」
  - Given 訪客開啟林沖資料 / When 點關係清單中的「魯智深」 / Then 面板切換為魯智深資料

### US-06 地圖檢視事件地點

| As a ... | I want to... | so that... |
| :---- | :---- | :---- |
| 訪客 | 在地圖上看篩選後的事件發生在哪裡 | 理解角色在各地的行跡 |

- **需求來源**：2026-10-20 需求討論（範圍確認：地圖視圖本階段要做）
- **定位**：時間軸的空間對照視圖，與時間軸共用同一組篩選。
- **角色與入口**：訪客；視圖切換點「地圖」，或事件明細點地點。
- **規則**：
  - 地圖為北宋疆域的示意地圖，地點標記位置為近似，頁面註明「示意，非精確測繪」
  - 只標出目前篩選結果中事件的地點，標記上顯示該地事件數
  - 只選一位角色時，依事件章回順序以虛線連接地點，呈現行跡
  - 點地點標記列出該地事件清單，點事件開啟事件明細
  - 地圖下方保留精簡章回刻度，顯示目前篩選範圍
- **狀態**：無
- **範圍**：
  - 涵蓋：示意地圖、地點標記與事件數、單一角色行跡線
  - 不涵蓋：真實地理底圖、縮放到城市街道層級、多角色行跡同時比對
- **邊界情況**：
  - 地點無法定位的事件不上地圖，地圖角落提示「N 個事件無法標示地點」
- **驗收條件**：
  - Given 只選武松 / When 切換到地圖 / Then 看到武松事件的地點標記與依章回順序的行跡線
  - Given 選了兩位以上角色 / When 切換到地圖 / Then 顯示地點標記但不畫行跡線

### US-07 角色關係網絡圖

| As a ... | I want to... | so that... |
| :---- | :---- | :---- |
| 訪客 | 看角色之間的結義、師徒、仇敵等關係 | 理解好漢們如何因人牽人聚上梁山 |

- **需求來源**：2026-10-20 需求討論（資料物件：角色關係；範圍確認：關係網絡圖本階段要做）
- **定位**：以人物關係補充時間軸，並可從關係圖直接挑選角色加入篩選。
- **角色與入口**：訪客；視圖切換點「關係圖」。
- **規則**：
  - 未選角色時顯示所有收錄角色與關係
  - 已選角色時，以已選角色為中心，只顯示他們及直接相連的角色，其餘淡出
  - 連線依關係類型區分樣式，並附圖例
  - 節點依星號群組（天罡／地煞／其他）區分顏色
  - 點節點開啟角色資料（US-05）；節點上的「＋」把該角色加入篩選
- **狀態**：無
- **範圍**：
  - 涵蓋：全體關係圖、以已選角色為中心的一層關係、圖例
  - 不涵蓋：關係隨章回演變的動態呈現、兩層以上的關係展開
- **驗收條件**：
  - Given 未選角色 / When 切換到關係圖 / Then 看到所有收錄角色與關係連線及圖例
  - Given 已選林沖 / When 切換到關係圖 / Then 林沖居中，只清楚顯示與林沖直接相連的角色

## 展示情境

### 訪客
1. 進站看到全書時間軸以大節分段，結果數「共 54 個事件」（US-01）
2. 搜尋「豹子頭」選取林沖，時間軸只剩林沖的事件（US-02）
3. 點「大鬧野豬林」看事件明細，點魯智深頭像加入篩選，時間軸變為兩人事件聯集（US-04、US-02）
4. 點林沖名字開啟角色資料，看狀態條從在野、上梁山到結局（US-05）
5. 按「只看此角色」，切換到地圖看林沖的行跡線（US-05、US-06）
6. 切換到關係圖，看林沖與魯智深、高俅等人的關係，點節點開啟對方資料（US-07）
